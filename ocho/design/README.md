# Folder desain

Ekspor tiap layar dari Figma sebagai PNG ke folder ini.

Cara ekspor di Figma:
1. Pilih satu frame (klik namanya di panel kiri atau di kanvas).
2. Di panel kanan, cari bagian "Export", klik "+", pilih PNG dan skala 2x.
3. Klik "Export ..." lalu simpan ke folder ini.

Nama file yang disarankan:
- desktop-00-login.png
- desktop-01-home.png
- desktop-02-detail-checkout.png
- desktop-03-qris.png
- mobile-00-login.png
- mobile-01-beranda.png
- mobile-02-detail-checkout.png
- mobile-03-qris.png
